# SQUEEZ Web

Website statis sederhana 3 halaman:
- index.html — Beranda
- produk.html — Produk
- tentang.html — Tentang & kontak

Teknologi:
- HTML
- CSS
- JavaScript vanilla
- Tanpa framework dan tanpa backend

Cara menjalankan:
1. Buka folder ini.
2. Jalankan `index.html` di browser.
3. Pastikan folder `assets` dan file `squeez.png` tetap berada di lokasi yang sama.

Catatan:
Harga produk dan kontak masih contoh dan dapat diganti.
